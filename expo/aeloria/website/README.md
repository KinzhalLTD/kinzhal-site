# Website for Aeloria

The pages already exist on kinzhal.space, so nothing needs to be hosted separately:

| Page | URL |
|---|---|
| Game page (Marketing URL) | https://kinzhal.space/aeloria/ |
| Support | https://kinzhal.space/aeloria/support/ |
| Privacy Policy | https://kinzhal.space/aeloria/privacy/ |
| Terms | https://kinzhal.space/aeloria/terms/ |
| app-ads.txt | https://kinzhal.space/app-ads.txt |

`app-ads.txt` in this folder is the exact line that must appear at https://kinzhal.space/app-ads.txt, at the root of the domain, the same domain as the Marketing URL. The kinzhal-site repository publishes it from `site.json` when its `main` branch deploys on Netlify.
