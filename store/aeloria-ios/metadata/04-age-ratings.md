# 4. Age Ratings

App Store Connect → **App Information → Age Rating → Edit**. Apple calculates the final rating from these answers.

## In-app controls and capabilities

| Question | Answer | Why |
|---|---|---|
| Parental controls | No | |
| Age assurance | No | |
| Unrestricted web access | No | The app does not open arbitrary web pages. |
| User-generated content | No | There is no free-text sharing between players. Alliance chat and arena rivals are computer-controlled. |
| Messaging and chat | No | |
| Advertising | **Yes** | Google AdMob: rewarded, interstitial, app-open, banner and native ads. AdMob's max ad content rating is set to G/PG and sensitive categories are blocked. |

## Violence

| Question | Answer |
|---|---|
| Cartoon or fantasy violence | **Frequent / Intense**: battles are the core loop. They are painted fantasy armies with damage numbers, with no blood or gore. If you judge them mild, choose Infrequent / Mild. |
| Realistic violence | None |
| Prolonged graphic or sadistic violence | None |
| Guns or other weapons | Infrequent / Mild: swords, bows and spears in a fantasy setting, no firearms |

## Chance-based activities

| Question | Answer |
|---|---|
| Gambling (real money) | No |
| Simulated gambling | None. The daily Wheel of Fortune is a free spin with no wagering. |
| Contests | None |
| Loot boxes | **Yes**. Crown Summon gives random heroes for gems, which can be bought. Odds are shown in the game (Legendary 4%, Epic 21%, Rare 75%), with a guarantee every 40 summons, as App Review Guideline 3.1.1 requires. |

## Expected result

Apple will most likely rate the app **9+**. Answering "Yes" to loot boxes can raise it to **13+**. Either is fine for this game, and the questionnaire must be answered truthfully.
